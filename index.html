The complete client

Everything below is implemented and shipping today.

01

Every platform

iPhone, iPad, Mac, Android, Windows and Linux — one app, one model. Light/dark themes, five interface languages, Apple icon choices, launch-at-login and hidden start on desktop.

iOSmacOSAndroidWindowsLinux
02

Subscriptions that stay organized

HTTPS downloads with optional Age encryption, per-source User-Agent, auto-update on a schedule or pull-to-refresh — plan usage and expiry shown on the group card when the provider reports them.

Ageplan infoauto-update
03

Provider configs, first-class

Remnawave and complete Xray JSON subscriptions import as provider-managed configs with their own routing — announcements, support and website links, expiry reminders and automatic address migration included.

04

Your nodes, your order

Manual groups, drag-to-arrange, favorites, per-source filters and batch latency tests — VMessAEAD/VLESS, Hysteria2, SS, SOCKS and Trojan share links, Xray JSON or QR scan on mobile.

05

Smart Routing

A direct region, split DNS resolvers, traffic sniffing and optional FakeDNS and fragment — preview the rule set before you connect, tune it without touching JSON.

06

Complete configs & Raw JSON

Run an entire Xray config as a connection resource — provider configs stay read-only and follow subscription updates; copy one into personal Raw JSON when you need to edit.

07

Multi-entry & least latency

Spread new connections across your fastest entry nodes — round-robin by default or least-latency probing, with live chain health on the connect page.

08

LAN proxy share

Offer an unauthenticated HTTP/SOCKS5 inbound on your LAN with one switch — other devices on the network can route through your connection.

09

Backup that's yours

A single-file backup to iCloud Drive, a OneDrive-synced folder or Android storage — optional scheduled writes, restore with a preview first. Honestly labelled as unencrypted.

10

System integrations

iOS home/lock-screen widgets and a Control Center button, Android widget and quick-settings tile, desktop tray with start/stop and server switching, mobile quick actions.

11

Real diagnostics

"Why this connection" explains the actual entry and final exit; the Xray page exposes the running config, logs and a read-only diagnostics view — no fake green lights.

12

External interfaces

A local HTTP API on desktop (localhost only, token-authorized) and Android broadcast automation — start, stop and reconfigure from scripts or other apps you trust.

Qubiq provides no VPN access or proxy servers — it is a client for servers and subscriptions you bring yourself.

Private by design

No accounts, no analytics, no telemetry — and no cloud of ours, because there isn't one.

Open source, GPL-3.0Read it, audit it, build it yourself — based on OneXray.
Nothing leaves your deviceNodes, credentials, Age keys and settings live in the local database — optional logs never leave the device.
No third-party telemetryNo analytics SDK, no crash reporting, no ads — the only requests are to your servers and providers.
Device identity is a random UUIDOptional HWID binds devices to a provider account — it's generated per source, never a hardware ID, and can be switched off.
Honest backupThe backup file is deliberately unencrypted — you're told before it's written, and you choose where it lives.
