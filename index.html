Documentation Guides, help and technical documentation for Qubiq

Sound familiar?

"A different VPN client on every device — every one configured differently."

One client everywhere.

Phone, tablet and desktop share the same servers model, the same routing controls and the same five interface languages — learn it once.

"My provider's app is a black box that phones home."

Open by default.

GPL-3.0 source you can build yourself, no accounts, no advertising, no analytics — Qubiq talks only to your servers and your provider.

"Every subscription refresh wipes my favorites and order."

Refresh keeps what's yours.

Favorites, pinned selections and provider order survive updates — new nodes merge into your setup instead of overwriting it.

"All-or-nothing tunnel — I want some traffic direct."

Routing you control.

Smart Routing compiles the split for app-managed connections, traffic modes switch from the desktop tray — or let your provider's config carry its own routing.

"The panel moved domains and every client broke."

Migrations are automatic.

Provider new-url/new-domain responses move the subscription to its new address on the next refresh — no re-adding, no QR-code hunt.

"Sign up for an account… to connect to my own server?"

Bring your own servers.

Qubiq provides no VPN access and sells nothing. Import share links, subscriptions or Xray JSON and go.

The complete client

Everything below is implemented and shipping today.

01

Every platform

iPhone, iPad, Mac, Android, Windows and Linux — one app, one model. Light/dark themes, five interface languages including RTL Persian, Apple icon choices, launch-at-login and hidden start on desktop.

iOSmacOSAndroidWindowsLinux
02

A home that stays simple

One screen: a connect hero above and your servers grouped by subscription below. Tap a row to pin it, double-tap to connect, long-press to favorite — pull down to refresh every source.

03

Subscriptions that stay organized

HTTPS downloads with automatic updates and pull-to-refresh — plan usage, expiry, announcements, support and website links on each group card when the provider reports them.

plan infoauto-updatemigration
04

Provider configs, first-class

Remnawave and complete Xray JSON subscriptions import as provider-managed configs that run their own routing — expiry reminders and automatic address migration included.

05

Smart Routing

App-managed connections compile Smart Routing with a direct region, split DNS and traffic sniffing — traffic modes switch from the desktop tray without opening a settings tree.

06

Complete configs & Raw JSON

Run an entire Xray config as a connection resource — provider configs stay read-only and follow subscription updates; a personal Raw copy is there when you need to edit.

07

Multi-entry & least latency

Spread new connections across your fastest entry nodes — round-robin by default or least-latency probing, with honest per-chain status while connected.

08

Honest status

The hero shows the real phase — Connect, Cancel, Disconnect, Try Again — with the running server name, an elapsed clock and the actual failure reason. No fake green lights.

09

Backup that's yours

A single-file backup to iCloud Drive, a OneDrive-synced folder or Android storage — optional scheduled writes, restore with a preview first. Honestly labelled as unencrypted.

10

System integrations

iOS home/lock-screen widgets and a Control Center button, Android widget and quick-settings tile, desktop tray with start/stop, reconnect and traffic-mode switching, mobile quick actions.

Qubiq provides no VPN access or proxy servers — it is a client for servers and subscriptions you bring yourself.

Private by design

No accounts, no analytics, no telemetry — and no cloud of ours, because there isn't one.

Open source, GPL-3.0Read it, audit it, build it yourself — based on OneXray.
Nothing leaves your deviceNodes, credentials, Age keys and settings live in the local database — optional logs never leave the device.
No third-party telemetryNo analytics SDK, no crash reporting, no ads — the only requests are to your servers and providers.
Device identity is a random UUIDHWID sent to a provider is generated per source — never a hardware, ad or system identifier.
Honest backupThe backup file is deliberately unencrypted — you're told before it's written, and you choose where it lives.
