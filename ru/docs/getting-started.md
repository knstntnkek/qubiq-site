# Начало работы

Qubiq — кроссплатформенный Xray-core клиент. Он **не предоставляет
VPN-доступ и собственных серверов** — вы приносите ссылки, подписку от
провайдера или Xray JSON, а Qubiq запускает туннель.

## Установка <!-- #install -->

Пакеты публикуются на этом сайте — см.
[раздел загрузки](index.html#modal-download).

| Платформа | Пакет | Требования |
| --- | --- | --- |
| iPhone / iPad | `Qubiq-ios.ipa` | iOS / iPadOS 16+, sideload или корпоративная подпись |
| macOS | `Qubiq-macos-universal.dmg` | macOS 13+, Apple silicon или Intel |
| Android | `Qubiq-android-universal.apk` | Android 10+, arm64-v8a или x86_64 |
| Windows | `Qubiq-windows-amd64.exe` / `.zip` · `Qubiq-windows-arm64.exe` / `.zip` | Windows 10 20H2+ (x64) или Windows 11 (ARM64) |
| Linux | `Qubiq-linux-x86_64.deb` / `.rpm` / `.zip` · `Qubiq-linux-aarch64.deb` / `.rpm` / `.zip` | Linux 5.3+, glibc 2.39+ |

## Первый запуск <!-- #first-run -->

Мастера настройки нет — приложение сразу открывает главный экран
**«Подключение»**. При первом запуске инициализируются база данных,
встроенные Geodata и координатор подключений, затем приложение просит
системные разрешения ниже — каждое один раз. Отказ всё равно пускает
внутрь; разрешение спросят снова при реальном подключении.

- **iOS / macOS / Android** — системный запрос на VPN. На версиях
  Android, где это нужно, спрашивается также разрешение на локальную
  сеть.
- **macOS (сборка System Extension)** — разрешите расширение один раз:
  - macOS 15+: *Системные настройки → Основные → Объекты входа и
    расширения → Сетевые расширения*
  - macOS 14 и раньше: *Системные настройки → Конфиденциальность и
    безопасность*

  Если к моменту подключения разрешение ещё не дано, Qubiq показывает
  пояснение с кнопкой **«Открыть настройки системы»** и повторяет
  активацию при следующей попытке.
- **Windows (EXE/ZIP)** — первое подключение один раз повышает права
  встроенного `QubiqCoreLauncher.exe` через UAC, регистрируя задачи
  *Qubiq VPN Core* в планировщике; дальше UAC не нужен. Сборка MSIX
  использует упакованный системный VPN.
- **Исходящий интерфейс на Windows / Linux** — Qubiq перепроверяет
  сохранённый исходящий интерфейс перед каждым подключением; если его
  нет или он недействителен, выбрать предложат в этот момент.
- **Linux** — ядру нужны право на исполнение, TUN и capabilities;
  пакеты .deb и .rpm настраивают это сами, для .zip может потребоваться
  ручная настройка.

## Добавьте сервер <!-- #add-a-server -->

Нажмите **＋** в шапке — или, на пустом главном экране, кнопку подключения
либо **«Добавить подключение»**, — чтобы открыть импорт:

- **Подписка** — вставьте HTTPS-URL от провайдера или нажмите кнопку
  `qubiq://add` на его панели — откроется та же форма с заполненными
  полями. Панель и режим определяются содержимым ответа.
- **Ссылки** — VMessAEAD/VLESS, старые QR VMess, WireGuard, Hysteria2,
  SS, SOCKS, Trojan — по одной на строку.
- **Скан QR-кода** — iOS и Android.
- **Файл** — через системный диалог выбора.

Подробности — в [«Серверы и узлы»](servers.md) и
[«Подписки и провайдеры»](subscriptions.md).

## Подключение <!-- #connect -->

Весь цикл умещается на главном экране:

- Нажмите строку сервера, чтобы **закрепить** её, — или ничего не
  закрепляйте и доверьте выбор автовыбору.
- Нажмите **кнопку подключения** — или **дважды нажмите строку**, чтобы
  закрепить и подключиться за один раз.
- При подключении показываются имя работающего сервера и таймер;
  избранное живёт в *«Настройки → Расширенные → Серверы»*.

Потяните список вниз, чтобы обновить все подписки. Полная модель — в
[«Подключение и системные интеграции»](connect.md).
